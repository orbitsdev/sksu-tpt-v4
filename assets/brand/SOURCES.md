## Colours

- Website theme (sksu.edu.ph CSS): green `#009a3c` (used 20×), yellow `#fffe00`.
- Seal and logo page (https://sksu.edu.ph/sksu-seal-and-logo/): "MINT GREEN is the color adopted for SULTAN KUDARAT STATE UNIVERSITY." The seal also uses yellow rays, light blue, orange, maroon and navy blue, and black rims.
- TPT v4 uses green `#009A3C` as the brand colour (the same as the website), `#007A30` for buttons with white text, blue `#007CC2` for charts, and yellow only for small accents.
