Guide · Applications

What this page is for

Every application in a schedule, with what each person needs next.

How it works

  1. Click a status tab to see one group, for example Waiting for payment.
  2. Search a name, examinee no., application code or OR no.; an exact number opens the record.
  3. Each row shows the one action that fits it: Remind, Pick slot, Resend permit.
  4. Click a row to see the person's steps and details.
  5. Select rows to remind or export several at once.

Examples

  • Waiting for payment · 790: remind them before registration closes.
  • Approved, no exam slot · 627: pick a slot for them, or they are seated automatically.
