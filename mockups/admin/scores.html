Guide · Import scores

What this page is for

Brings in the Testing Center's results Excel. The system never computes or changes scores; it checks the file and saves them exactly as given.

How it works

  1. Upload the Excel as it is.
  2. Check the column match once (it is remembered for next year).
  3. Look at the rows that need a look; fix them with the Testing Center or upload again.
  4. Approve: scores are saved but still hidden.
  5. Publish on the Results page.

Examples

  • Examinee no. with the letter O instead of zero is flagged.
  • Someone with an exam slot but no score is marked absent when you approve.
