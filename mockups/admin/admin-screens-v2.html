Admin screens, new design

The admin screens in flow order, in the same style as your approved Dashboard and Exam schedules. All names and numbers are samples. Each screen is shown as a laptop and as a phone.

Across every admin page
  • The dark Getting started bar shows on every page, even at "7 of 7 done". It moves to the Dashboard and goes away when done.
  • Page titles match the menu, and description lines go away unless a page would confuse without them.
  • Dropdowns, table headings and empty messages look the same on every page.
  • More space: wider margins, taller rows, softer lines and fewer boxes.
